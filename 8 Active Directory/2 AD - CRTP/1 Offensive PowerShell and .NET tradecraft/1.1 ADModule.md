# ADModule 

Tags: #Powershell #AD #Comandos 

## Importar ADModule 

```powershell 
❯ Import-Module Microsoft.ActiveDirectory.Management.dll
```

## Comandos 


```powershell 
❯ Get-ADDomain 
❯ Get-ADUser -Filter * 
❯ Get-ADForest | %{Get-ADTrust -Filter *}

# Lista todas las máquinas en el dominio, muestra SO, versión específica, y DNSHostName completo para resolución
❯ Get-ADComputer -Filter * -Properties OperatingSystem,OperatingSystemVersion,DNSHostName | Select-Object Name,OperatingSystem,OperatingSystemVersion,DNSHostName
```

```powershell
# Obtener todos los dominios en el bosque y lista las confianzas externas (no-transitivas).
❯ (Get-ADForest).Domains | %{Get-ADTrust -Filter '(intraforest -ne $true) -and (foresttransitive -ne $true)' -Server $_}

# Lista quién está en el grupo Domain Admins (target principal para DA).
❯ Get-ADGroupMember -Identity 'Domain Admins'

# Lo mismo pero solo muestra SamAccountName, Name y ObjectClass (más limpio).
❯ Get-ADGroupMember -Identity 'Domain Admins' | Select-Object SamAccountName,Name,ObjectClass

# Incluye miembros anidados (grupos dentro de Domain Admins).
❯ Get-ADGroupMember "Domain Admins" -Recursive | Select-Object Name,ObjectClass

# Lista todos los usuarios con datos sensibles (último logon, cuándo cambió contraseña, intentos fallidos).
❯ Get-ADUser -Filter * -Properties Description,MemberOf,LastLogonDate,PasswordLastSet,BadLogonCount | Select-Object SamAccountName,Name,Description,MemberOf,LastLogonDate,PasswordLastSet,BadLogonCount

# Mapea todas las confianzas entre dominios (critical para lateral movement).
❯ Get-ADTrust -Filter * | Select-Object Name,Source,Target,Direction,TrustType

Dump completo de las relaciones de confianzas.
❯ Get-ADTrust -Filter * -Properties *

# Encuentra máquinas que pueden hacer delegación (target para Kerberoasting).
❯ Get-ADComputer -Filter {TrustedForDelegation -eq $true} -Properties TrustedForDelegation,ServicePrincipalName,Description | Select-Object Name,ServicePrincipalName,Description

# Filtra por flag específico de UAC (524288 = TrustedForDelegation).
❯ Get-ADComputer -LDAPFilter "(&(userAccountControl:1.2.840.113556.1.4.803:=524288))" -Properties ServicePrincipalName,Description | Select-Object Name,ServicePrincipalName,Description

# Identifica usuarios con SPNs asignados (targets para Kerberoasting).
❯ Get-ADUser -Filter {ServicePrincipalName -like "*"} -Properties ServicePrincipalName | Select-Object SamAccountName,ServicePrincipalName
```
